테마 설치법

  1. 아이폰 저장을 눌러 .ktheme 파일을 다운로드해요.
  2. Safari 다운로드 목록 또는 파일 앱에서 파일을 열고 카카오톡으로 열기를 선택해요.
  3. 카카오톡 더보기 · 설정 · 테마로 이동해요.
  4. 내 테마에서 방금 받은 테마를 선택하고 적용하기를 눌러요.

Android 9 이상에서 사용할 수 있어요. 테마 생성 중에는 이 페이지를 열어두세요.

  1. 색상·말풍선·배경 이미지를 설정한 뒤 안드로이드 저장을 눌러요.
  2. 버튼에 생성 단계가 표시돼요. 완료까지 몇 분 걸릴 수 있어요.
  3. 저장 준비 완료가 표시되면 같은 안드로이드 저장 버튼을 한 번 더 눌러 APK 파일을 저장해요. 저장 링크는 생성 요청 후 약 25분 동안 유효해요.
  4. 휴대폰의 다운로드 목록이나 파일 앱에서 APK를 열고 설치해요. 필요한 경우 해당 브라우저 또는 파일 앱의 이 출처 허용을 켜주세요. PC에서 저장했다면 APK를 휴대폰으로 옮겨 설치해주세요.
  5. 설치된 테마 앱의 테마 적용하기를 누르거나, 카카오톡 더보기 · 설정 · 테마에서 받은 테마를 선택하고 적용해요.
  6. 같은 이름으로 다시 만든 테마는 기존 테마를 업데이트해요. 다른 테마로 보관하려면 이름을 바꿔주세요. 저장 링크가 만료됐다면 안드로이드 저장을 눌러 다시 생성해주세요.
