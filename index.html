테마 설치법

  1. 아이폰 저장을 눌러 .ktheme 파일을 다운로드해요.
  2. Safari 다운로드 목록 또는 파일 앱에서 파일을 열고 카카오톡으로 열기를 선택해요.
  3. 카카오톡 더보기 · 설정 · 테마로 이동해요.
  4. 내 테마에서 방금 받은 테마를 선택하고 적용하기를 눌러요.
카카오 공식 iOS 설치 안내 ↗

현재 Android 버튼은 APK가 아닌 Android Studio 빌드용 프로젝트 ZIP을 저장해요. 압축을 푼 뒤 Android Studio와 JDK 21, Android SDK 35에서 여세요.

  1. ZIP을 풀고 Android Studio에서 프로젝트 폴더를 열어요.
  2. Gradle 동기화가 끝나면 Build · Build APK(s)를 실행해요.
  3. 생성된 APK를 휴대폰으로 옮겨 설치해요.
  4. 카카오톡 더보기 · 설정 · 테마에서 테마를 선택해요.
